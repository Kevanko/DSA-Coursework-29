# DSA-Coursework-29

Bloom filter coursework for data structures and algorithms.

## Overview

This repository contains an academic implementation of a Bloom filter prepared as coursework for the data structures and algorithms course.

## Structure

- `src` - source files
- `Makefile` - build instructions
- `bin`, `obj` - generated build artifacts

## Stack

C, Makefile.

## Notes

This repository is intended as a coursework submission and demonstration of the Bloom filter data structure.
